# Semaine 1 — BTS SIO

## Du réseau mondial à ma première page Web

Bienvenue dans votre première semaine technique de BTS SIO.

Vous n'avez **pas besoin d'avoir déjà programmé**. Cette semaine est conçue pour des personnes qui découvrent l'informatique technique, le Web et le code. Si certains mots utilisés ici vous sont inconnus, c'est normal : nous allons les apprendre ensemble.

L'objectif n'est pas d'aller vite. L'objectif est de comprendre, pratiquer, se tromper, corriger et devenir progressivement autonome.

## Ce que vous saurez faire vendredi soir

À la fin de la semaine, vous devriez être capable de :

- expliquer avec des mots simples la différence entre **Internet** et **le Web** ;
- expliquer les rôles d'un navigateur, d'un client et d'un serveur ;
- expliquer à quoi servent une adresse IP, un nom de domaine, le DNS et HTTP ;
- reconnaître les grandes parties d'une URL ;
- organiser correctement des fichiers et des dossiers ;
- utiliser Visual Studio Code pour travailler sur un projet simple ;
- créer une page HTML valide et structurée ;
- utiliser des titres, paragraphes, listes, liens et images ;
- créer plusieurs pages HTML et les relier entre elles ;
- comprendre et corriger quelques erreurs fréquentes ;
- tester le travail d'un camarade avec une checklist ;
- expliquer ce que vous avez réalisé et les difficultés rencontrées.

Il ne vous est pas demandé de tout retenir immédiatement. Les notions seront réutilisées tout au long de votre formation.

## Les règles de la semaine

### 1. Vous avez le droit de ne pas savoir

Dire « je ne sais pas » n'est pas un problème. Ne pas poser de question alors que vous êtes perdu en devient rapidement un.

### 2. On lit les messages d'erreur et on observe avant de demander de l'aide

Quand quelque chose ne fonctionne pas, commencez par vérifier :

- ai-je enregistré mon fichier ?
- est-ce le bon fichier ?
- est-ce le bon dossier ?
- ai-je correctement écrit le nom du fichier ?
- l'extension est-elle correcte ?
- ai-je oublié un guillemet, un `>` ou une balise ?

Consultez ensuite [Je suis bloqué : que faire ?](RESSOURCES/Je_suis_bloque.md).

### 3. Copier du code sans le comprendre ne constitue pas un apprentissage

Vous pouvez comparer votre travail avec un exemple, mais vous devez être capable d'expliquer ce que fait chaque partie que vous utilisez.

### 4. Les plus rapides ne changent pas le rythme du groupe

Des challenges supplémentaires sont proposés. Si vous terminez avant les autres, réalisez-les sans perturber les personnes qui ont besoin de davantage de temps.

### 5. On s'entraide sans faire à la place de l'autre

Une bonne aide consiste à poser des questions et à orienter :

> « Quel fichier essaies-tu d'ouvrir ? »

> « Où se trouve ton image ? »

> « Quel chemin as-tu écrit ? »

Une mauvaise aide consiste à prendre le clavier du camarade et à faire le travail à sa place.

## Matériel nécessaire

Vous aurez besoin de :

- votre ordinateur ;
- un navigateur Web moderne ;
- Visual Studio Code, installé mardi avec le groupe ;
- un dossier de travail facile à retrouver ;
- de quoi prendre quelques notes.

**Git n'est pas un prérequis cette semaine.** Vous consultez ce dépôt comme un support pédagogique. L'apprentissage du versionnement viendra progressivement.
