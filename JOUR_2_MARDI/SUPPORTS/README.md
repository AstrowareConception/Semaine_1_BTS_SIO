# Supports du mardi

## Support projeté

[Support complet des activités du mardi](Support_projection_activites_mardi.pptx)

Le diaporama comporte 100 diapositives :

- diapositives 1 à 3 : ouverture et parcours ;
- diapositives 4 à 13 : réactivation du lundi ;
- diapositives 14 à 24 : jeu « HTML, CSS ou JavaScript ? » ;
- diapositives 25 à 40 : extensions, arborescence vivante et chemins ;
- diapositives 41 à 48 : checkpoints Visual Studio Code ;
- diapositives 49 à 59 : puzzle du squelette HTML et première page ;
- diapositives 60 à 69 : chasse aux erreurs ;
- diapositives 70 à 78 : tribunal des listes ;
- diapositives 79 à 93 : liens, images, chemins et textes alternatifs ;
- diapositives 94 à 100 : mission finale, relecture et ticket de sortie.

Les réponses et conseils d'animation figurent dans les notes du présentateur. Les écrans de correction sont également intégrés au diaporama.

## Fichiers à manipuler

Les [ateliers du mardi](../ATELIERS/README.md) fournissent les fichiers de départ pour :

- remettre un squelette HTML dans l'ordre ;
- réparer une page contenant plusieurs erreurs ;
- corriger des liens et chemins d'images ;
- construire la page finale à partir d'un squelette guidé.

Le corrigé enseignant se trouve dans [Corrigés et conseils d'animation — Mardi](../../ENSEIGNANT/Corriges_ateliers_mardi.md).
