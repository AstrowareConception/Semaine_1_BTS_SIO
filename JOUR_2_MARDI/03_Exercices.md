# Exercices du mardi

Effectuez les exercices dans l'ordre. Le but n'est pas de terminer le plus vite possible.

Avant les exercices de création, réalisez les [ateliers manipulables](ATELIERS/README.md). Ils permettent de travailler le diagnostic, les chemins et la lecture du code avec des fichiers déjà préparés.

# Exercice 1 — Ma première page

Créez un dossier :

```text
exercice_1
```

Créez `index.html`.

Votre page doit contenir :

- un titre d'onglet ;
- un `h1` contenant « Ma première page » ;
- deux paragraphes ;
- un mot important avec `strong` ;
- une expression avec `em`.

Une fois terminé, fermez puis rouvrez votre fichier pour vérifier que le travail a bien été enregistré.

---

# Exercice 2 — Mes trois technologies

Créez une page présentant :

```text
HTML
CSS
JavaScript
```

Vous n'avez pas besoin de connaître ces technologies en détail. Utilisez les descriptions fournies en cours.

Contraintes :

- un `h1` ;
- trois `h2` ;
- au moins un paragraphe sous chaque `h2` ;
- une liste récapitulative.

---

# Exercice 3 — Liste de préparation

Créez une liste ordonnée expliquant comment :

1. créer un dossier de projet ;
2. l'ouvrir dans VS Code ;
3. créer `index.html` ;
4. enregistrer ;
5. ouvrir le fichier dans le navigateur.

Puis créez une liste non ordonnée contenant cinq outils, logiciels ou technologies informatiques que vous connaissez de nom.

---

# Exercice 4 — Ajouter un lien

Ajoutez dans votre page un lien vers un site de documentation ou d'information choisi avec l'enseignant.

Vérifiez vous-même :

- le texte est cliquable ;
- la destination est correcte ;
- vous n'avez pas oublié les guillemets.

---

# Exercice 5 — Ajouter une image locale

Créez cette structure :

```text
exercice_5/
├── index.html
└── images/
    └── illustration.jpg
```

Placez une image autorisée dans le dossier `images` et affichez-la depuis `index.html`.

Ajoutez un texte `alt` qui décrit réellement l'image.

## Si l'image ne s'affiche pas

Ne changez rien au hasard. Vérifiez :

1. le nom exact du fichier ;
2. son extension ;
3. le dossier où il se trouve ;
4. le contenu de `src` ;
5. si le fichier HTML a été enregistré.

---

# Exercice 6 — Page complète

Créez une page consacrée à un **personnage fictif passionné d'informatique**.

N'utilisez pas de données personnelles réelles si vous ne souhaitez pas les publier ou les montrer.

La page doit contenir :

- un titre principal ;
- une courte présentation ;
- une section « Compétences qu'il souhaite apprendre » ;
- une liste ;
- une section « Centres d'intérêt » ;
- une image ;
- un lien externe ;
- au moins trois paragraphes.

Veillez à l'indentation.

---

# Relecture croisée

Travaillez en binômes avec deux rôles :

- le **pilote** présente sa page puis ne touche plus au clavier pendant deux minutes ;
- l'**observateur** teste la page, lit le code et formule son retour sans prendre le clavier.

Vérifiez :

- [ ] la page s'ouvre ;
- [ ] le titre principal est identifiable ;
- [ ] les paragraphes sont structurés ;
- [ ] la liste fonctionne ;
- [ ] le lien fonctionne ;
- [ ] l'image apparaît ;
- [ ] l'image possède `alt` ;
- [ ] le code est lisible.

Donnez ensuite **un point positif** et **une amélioration possible**.

Le pilote choisit la correction à appliquer, puis les rôles sont inversés.
