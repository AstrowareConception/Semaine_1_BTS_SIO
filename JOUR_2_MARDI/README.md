# Jour 2 — Mardi

# Installer son environnement et écrire ses premières pages HTML

Aujourd'hui vous allez écrire vos premières lignes de code HTML.

Nous avançons volontairement lentement. Chaque notion sera immédiatement manipulée.

## Objectifs

À la fin de la journée, vous devriez pouvoir :

- expliquer la différence générale entre HTML, CSS et JavaScript ;
- créer et organiser des fichiers et dossiers ;
- ouvrir un dossier dans Visual Studio Code ;
- créer un fichier `index.html` ;
- écrire la structure minimale d'une page ;
- utiliser des titres et paragraphes ;
- créer des listes ;
- créer un lien ;
- afficher une image locale ;
- comprendre un chemin relatif simple.
