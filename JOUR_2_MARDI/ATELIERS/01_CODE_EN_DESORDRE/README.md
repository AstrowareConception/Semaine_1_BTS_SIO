# Mission 1 — Le code en désordre

## Objectif

Reconstruire le squelette minimal d'une page HTML sans commencer par copier un modèle déjà ordonné.

## Consigne

Recopiez les fragments suivants sur une feuille ou dans un fichier temporaire, puis remettez-les dans un ordre logique :

```html
</body>
<head>
<h1>Bonjour le Web !</h1>
<!DOCTYPE html>
</html>
<body>
<title>Ma première page</title>
<html lang="fr">
<meta charset="UTF-8">
</head>
```

## Validation

Votre proposition doit :

- commencer par la déclaration du type de document ;
- contenir un élément `html` ;
- séparer correctement `head` et `body` ;
- placer `title` au bon endroit ;
- fermer tous les éléments ouverts ;
- afficher « Bonjour le Web ! » dans la page.

Expliquez à votre binôme le rôle de trois lignes de votre choix.
