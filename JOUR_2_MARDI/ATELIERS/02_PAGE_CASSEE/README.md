# Mission 2 — La page cassée

Le fichier `index.html` contient plusieurs erreurs volontaires.

## Méthode imposée

Pour chaque erreur :

1. observez le résultat dans le navigateur ;
2. localisez une zone suspecte ;
3. notez votre diagnostic ;
4. corrigez uniquement cette erreur ;
5. enregistrez et actualisez ;
6. vérifiez avant de passer à la suivante.

## Livrable

Lorsque la page fonctionne, ajoutez à la fin du fichier un commentaire HTML contenant le nombre d'erreurs que vous avez corrigées.

Exemple :

```html
<!-- J'ai corrigé 6 erreurs. -->
```

Ne remplacez pas tout le fichier par un autre squelette. L'objectif consiste à diagnostiquer.
