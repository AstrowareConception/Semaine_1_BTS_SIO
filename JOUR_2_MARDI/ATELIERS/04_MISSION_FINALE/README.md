# Mission finale — Le personnage impossible

Créez une page présentant un personnage fictif passionné d'informatique et doté d'un détail volontairement improbable.

Vous pouvez partir du fichier `index.html` fourni, mais vous devez remplacer les commentaires par votre propre contenu.

## Éléments obligatoires

- un titre d'onglet pertinent ;
- un titre principal `h1` ;
- au moins deux sections introduites par `h2` ;
- au moins trois paragraphes ;
- une information importante avec `strong` ;
- une emphase avec `em` ;
- une liste ordonnée ou non ordonnée choisie pour une raison précise ;
- un lien externe fonctionnel ;
- une image rangée dans un dossier `images` ;
- un attribut `alt` utile ;
- un code indenté et relisible.

## Contraintes créatives

Votre personnage doit posséder :

- un métier ou un rôle informatique ;
- une passion improbable ;
- un petit incident technique qu'il a dû diagnostiquer.

## Autocontrôle

Avant de demander de l'aide, vérifiez l'enregistrement, l'actualisation, les noms de fichiers, les extensions, les chemins, les balises et les guillemets.
