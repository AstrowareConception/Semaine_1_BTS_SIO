## Règle commune

Avant de modifier un fichier qui ne fonctionne pas :

1. décrire ce qui était attendu ;
2. décrire ce qui est réellement observé ;
3. formuler une hypothèse ;
4. ne modifier qu'un élément ;
5. enregistrer, actualiser et vérifier.

Le corrigé et les conseils d'animation se trouvent dans le dossier `ENSEIGNANT`.
