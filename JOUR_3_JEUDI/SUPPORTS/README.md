# Supports du jeudi

## Diaporama de révision et d'animation

[`Revision_HTML_Jeudi_Jeux_Defis_Quiz.pptx`](Revision_HTML_Jeudi_Jeux_Defis_Quiz.pptx) accompagne une demi-journée complète de révision vivante :

- vrai ou faux de réactivation ;
- quiz des fondamentaux ;
- chasse aux bugs ;
- défis sur les chemins relatifs ;
- jeu « Qui suis-je ? » consacré aux balises ;
- mini-site final en équipe, recette croisée et votes de la classe.

Les 79 diapositives alternent questions et corrections. Les notes du présentateur rappellent les réponses, le minutage et les consignes d'animation. Chaque manche peut être raccourcie ou ignorée selon l'avancement réel de la classe.

## Kit facultatif de mise en forme

Le travail demandé porte sur le HTML. Le CSS est fourni uniquement pour rendre les productions plus agréables à présenter.

## Utilisation la plus simple

1. Copiez `theme-fourni.css` à côté de votre fichier `index.html`.
2. Ajoutez dans le `head` :

```html
<link rel="stylesheet" href="theme-fourni.css">
```

3. Ne modifiez pas le fichier CSS.
4. Vérifiez aussi votre page après avoir retiré temporairement la ligne : elle doit rester compréhensible.

Le dossier [`KIT_DEPART`](KIT_DEPART/) contient un exemple déjà relié au thème.
