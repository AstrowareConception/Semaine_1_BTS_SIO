# Kit facultatif de mise en forme

Le travail demandé porte sur le HTML. Le CSS est fourni uniquement pour rendre les productions plus agréables à présenter.

## Utilisation la plus simple

1. Copiez `theme-fourni.css` à côté de votre fichier `index.html`.
2. Ajoutez dans le `head` :

```html
<link rel="stylesheet" href="theme-fourni.css">
```

3. Ne modifiez pas le fichier CSS.
4. Vérifiez aussi votre page après avoir retiré temporairement la ligne : elle doit rester compréhensible.

Le dossier [`KIT_DEPART`](KIT_DEPART/) contient un exemple déjà relié au thème.
