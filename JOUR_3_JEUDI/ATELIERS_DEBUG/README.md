# Ateliers de débogage

Chaque dossier contient une page volontairement cassée. Travaillez sur une **copie** du dossier.

## Méthode obligatoire

1. Ouvrez la page dans le navigateur.
2. Décrivez le problème sans toucher au code.
3. Repérez la ligne probablement responsable.
4. Effectuez une seule correction.
5. Rechargez et recommencez.

## Rotation conseillée

| Atelier | Problème dominant | Indice à révéler si nécessaire |
|---|---|---|
| 1 | balises et titres | comparez ouverture et fermeture |
| 2 | imbrication | regardez où se ferment les `li` |
| 3 | chemin d'image | partez du fichier HTML |
| 4 | navigation | `..` signifie « dossier parent » |
| 5 | tableau et formulaire | associez chaque `label` à un `id` |
| 6 | plusieurs erreurs | corrigez d'abord la structure générale |

Les ateliers correspondent aux exercices 29 à 34 de la [banque d'exercices](../04_BANQUE_40_EXERCICES.md).
