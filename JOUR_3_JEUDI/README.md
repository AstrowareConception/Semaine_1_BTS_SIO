# Jour 3 — Jeudi

# Laboratoire HTML : pratiquer toute la journée

Aujourd'hui, nous avons volontairement **peu de nouvelles notions**. Le but est de pratiquer, diagnostiquer, recommencer et devenir plus autonome.

Le but est de transformer ce que vous avez vu mardi en gestes que vous êtes capables de refaire avec moins d'aide.

## Objectifs

À la fin de la journée, vous devriez pouvoir :

- recréer une page HTML à partir d'un fichier vide ;
- utiliser sans modèle permanent les balises HTML déjà découvertes ;
- créer plusieurs fichiers HTML ;
- créer des liens entre ces fichiers ;
- créer un dossier `images` ;
- comprendre pourquoi une image ou un lien ne fonctionne pas dans plusieurs cas simples ;
- organiser un mini-site de plusieurs pages ;
- ajouter des commentaires HTML ;
- relire le travail d'un camarade.

Vous disposez de :

- [48 exercices, des micro-défis aux missions longues](04_BANQUE_40_EXERCICES.md) ;
- [trois parcours pour avancer à son rythme](05_PARCOURS_JOURNEE_COMPLETE.md) ;
- [six mini-projets au choix](06_MINI_PROJETS.md) ;
- [six ateliers avec des fichiers volontairement cassés](ATELIERS_DEBUG/README.md) ;
- [un thème CSS facultatif déjà prêt](SUPPORTS/README.md).

## Règle technique

Les productions utilisent **HTML uniquement**. Le fichier CSS fourni peut être relié aux pages pour embellir le résultat : il n'a pas besoin d'être compris ni modifié. Aucun JavaScript n'est nécessaire.

## Important

Le **niveau Essentiel** n'est pas un niveau « faible ». Il correspond aux fondamentaux que nous voulons réellement rendre autonomes.

Un étudiant ayant correctement terminé l'Essentiel a rempli l'objectif principal de la journée.

Le nombre d'exercices terminés compte moins que la capacité à tester, expliquer et corriger son travail.
