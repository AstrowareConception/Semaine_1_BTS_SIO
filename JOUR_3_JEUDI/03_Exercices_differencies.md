# Exercices différenciés du jeudi

Votre enseignant vous indiquera quand commencer cette partie.

Choisissez le niveau adapté à votre avancement. Il ne s'agit pas d'un classement définitif.

# Niveau 1 — Essentiel

## Objectif

Être capable de créer **seul** un petit site de deux pages.

Créez :

```text
essentiel/
├── index.html
├── seconde-page.html
└── images/
    └── illustration.jpg
```

### `index.html`

Doit contenir :

- un `h1` ;
- deux paragraphes ;
- une liste ;
- une image avec `alt` ;
- un lien vers `seconde-page.html`.

### `seconde-page.html`

Doit contenir :

- un `h1` ;
- un paragraphe ;
- une liste ;
- un lien de retour vers `index.html`.

### Validation

Vous devez être capable de montrer à l'enseignant :

1. où se trouvent vos fichiers ;
2. où se trouve l'image ;
3. pourquoi votre `src` fonctionne ;
4. pourquoi votre `href` fonctionne.

---

# Niveau 2 — Standard

Créez un site de trois pages sur le thème de votre choix parmi ceux validés en classe.

Contraintes :

- trois fichiers HTML ;
- un dossier `images` ;
- navigation entre toutes les pages ;
- plusieurs titres ;
- plusieurs paragraphes ;
- au moins deux listes ;
- au moins deux images avec `alt` ;
- au moins un lien vers un site externe ;
- commentaires HTML utiles ;
- indentation régulière.

### Bonus de qualité

Relisez votre site comme si vous le découvriez pour la première fois : les titres permettent-ils de comprendre immédiatement chaque page ?

---

# Niveau 3 — Challenge facultatif

Uniquement si les niveaux précédents sont terminés et validés.

Sans demander immédiatement la solution à l'enseignant, recherchez comment :

- créer un lien vers une adresse électronique ;
- créer un lien vers une partie précise de la même page avec un identifiant ;
- utiliser `figure` et `figcaption` pour associer une légende à une image ;
- ajouter une citation HTML adaptée.

Pour chaque nouveauté, vous devez être capable de répondre :

1. quelle balise ou quel attribut ai-je découvert ?
2. à quoi sert-il ?
3. où ai-je trouvé l'information ?
4. suis-je capable de le refaire sans copier l'exemple ?

Le challenge n'est pas une excuse pour introduire du CSS ou JavaScript aujourd'hui.
