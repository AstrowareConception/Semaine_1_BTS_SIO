# Activités et exercices du lundi

## Exercice 1 — Internet ou Web ?

Pour chaque situation, indiquez si elle concerne principalement Internet, le Web, ou si les deux notions interviennent.

1. Vous consultez une page Wikipédia avec Firefox.
2. Vous envoyez un courriel.
3. Vous ouvrez un site d'actualité.
4. Deux réseaux distants échangent des paquets.
5. Vous utilisez une application de visioconférence.
6. Vous cliquez sur un lien hypertexte dans une page.

Pour chaque réponse, écrivez **une phrase de justification**.

## Exercice 3 — Dessinez le voyage d'une page Web

Sur papier, dessinez un utilisateur qui souhaite visiter un site.

Votre schéma doit contenir au minimum :

- utilisateur ;
- navigateur ;
- réseau local ;
- Internet ;
- serveur.

Ajoutez ensuite le DNS au bon endroit dans votre explication.

Sous le schéma, écrivez cinq phrases maximum pour décrire ce qui se passe.

## Exercice 4 — Lire une URL

Observez :

```text
https://www.exemple.fr/formation/bts-sio/index.html
```

Répondez :

1. Quel est le protocole/schéma indiqué ?
2. Quel est le nom d'hôte ?
3. Quel est le chemin ?
4. Quel semble être le nom du fichier demandé ?

Puis inventez une URL plausible pour une page intitulée `contact.html` située dans un dossier `pages` du même site.

## Exercice 5 — Client ou serveur ?

Pour chaque proposition, indiquez le rôle décrit dans notre modèle simplifié.

1. Il envoie une demande de page.
2. Il reçoit une requête et produit une réponse.
3. Dans notre exemple, Firefox joue ce rôle.
4. Il peut héberger les fichiers nécessaires à un site.

Expliquez ensuite avec vos mots ce que signifie la phrase :

> « Le navigateur est un client HTTP. »

## Exercice 6 — Comprendre quelques réponses HTTP

Associez chaque situation au code le plus plausible parmi `200`, `404`, `500`.

1. La page demandée existe et arrive correctement.
2. L'utilisateur demande `/ancien-menu.html`, qui n'existe pas.
3. Le serveur rencontre une erreur interne pendant le traitement.

Vous n'avez pas besoin de connaître d'autres codes aujourd'hui.

# Activité collective — Le Web humain

Des étudiants vont jouer les rôles suivants :

- utilisateur ;
- navigateur/client ;
- DNS ;
- réseau ;
- serveur Web.

## Scénario A — Tout fonctionne

L'utilisateur veut consulter une page. La demande doit circuler entre les différents rôles jusqu'à ce que la réponse revienne.

À chaque étape, l'étudiant doit dire à haute voix ce qu'il représente.

## Scénario B — Ressource absente

Le serveur est joignable mais la ressource demandée n'existe pas.

Quel type de réponse peut-il renvoyer ?

## Scénario C — Nom inconnu

Le navigateur ne parvient pas à résoudre le nom demandé.

À quel moment le scénario se bloque-t-il ?
