# Supports d'animation du lundi

Ce dossier contient les supports directement utilisables pendant les activités collectives. Les diapositives de cours restent dans les supports dédiés.

## Bingo humain

- [Bingo humain projeté — 90 affirmations](Bingo_humain_projete_90_affirmations.pptx)
- Utilisation conseillée : trois passages par étudiant, avec relais, confirmation et vote rapide de la classe.

## Autres activités projetées

- [Support complet des activités du lundi](Support_projection_activites_lundi.pptx)

Repères dans le diaporama :

| Diapositives | Séquence |
|---:|---|
| 1–2 | Ouverture et mode d'emploi |
| 3–25 | Quiz diagnostic de 20 questions et repères enseignant |
| 26–43 | Défi « Internet, Web ou les deux ? » et corrections |
| 44–48 | Voyage simplifié d'une page Web |
| 49–54 | Classement et « procès des mots » |
| 55–61 | Réactivation, frise chronologique et analogie du DNS |
| 62–68 | URL, client, serveur et codes HTTP |
| 69–81 | Web humain et enquêtes collectives |
| 82–85 | Mini-bilan et ticket de sortie |

Le diaporama contient les questions, les situations, les consignes et les corrections. Les notes du présentateur apportent quelques indications supplémentaires pour l'enseignant.

## Web humain

- [Cartes de rôles, messages et scénarios à imprimer](Cartes_Web_humain.pdf)
- [Version Word modifiable du kit](Kit_Web_humain_acteurs_et_enqueteurs.docx)

Le PDF contient cinq pages : les règles, huit cartes de rôle, huit cartes message, quatre scénarios et une feuille d'enquête. Imprimer les cartes en recto simple et prévoir une feuille d'enquête par équipe. Les autres étudiants travaillent en groupes et rendent un diagnostic pour chaque scénario.
