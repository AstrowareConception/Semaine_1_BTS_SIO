# Histoire simplifiée d'Internet et du Web

Cette fiche ne cherche pas à raconter toute l'histoire des réseaux informatiques. Elle donne quelques repères pour comprendre comment nous sommes passés de réseaux expérimentaux à l'Internet et au Web utilisés aujourd'hui.

---

# 1. Avant Internet : faire communiquer des ordinateurs

Dans les années 1960, les ordinateurs sont rares, coûteux et généralement isolés. Plusieurs équipes de recherche travaillent alors sur une idée nouvelle : permettre à des machines distantes d'échanger des informations sur un réseau.

Un des principes importants qui se développe est celui de la **commutation de paquets** : au lieu de réserver une ligne entière pour une communication, les données peuvent être découpées en petits morceaux qui circulent sur le réseau.

Vous étudierez les réseaux beaucoup plus précisément plus tard. Pour cette première semaine, retenez surtout que l'idée de faire communiquer des machines distantes apparaît bien avant le Web.

---

# 2. 1969 — ARPANET

En 1969, les premiers nœuds d'**ARPANET** sont mis en relation aux États-Unis.

ARPANET est un réseau de recherche important dans l'histoire d'Internet. Ce n'est pas encore « Internet » tel que nous l'utilisons aujourd'hui, mais plusieurs idées, expérimentations et protocoles développés autour de ces réseaux contribueront à son émergence.

Un point essentiel :

> Internet n'a pas été inventé en une seule journée par une seule personne.

Il résulte d'une succession de recherches, de choix techniques et de standards permettant progressivement à des réseaux différents de communiquer.

---

# 3. Les protocoles TCP/IP

Pour que des réseaux différents puissent communiquer, il faut des règles communes.

Les protocoles **TCP/IP** deviennent fondamentaux dans la construction d'Internet.

Le 1er janvier 1983 est souvent retenu comme un jalon important : ARPANET bascule vers TCP/IP.

L'idée générale qui nous intéresse ici est simple :

> des réseaux et des machines différents peuvent communiquer s'ils utilisent des protocoles compatibles et partagent des règles communes.

Nous n'étudions pas encore le fonctionnement détaillé de TCP et IP.

---

# 4. Internet existe avant le Web

C'est une conséquence importante de la chronologie.

Au cours des années 1980, des réseaux interconnectés existent déjà. Des utilisateurs échangent des données et utilisent différents services.

Mais le **World Wide Web** n'existe pas encore.

Cela montre une nouvelle fois que :

> Internet et le Web ne sont pas synonymes.

Le Web arrivera plus tard et utilisera l'infrastructure Internet.

---

# 5. 1989 — Tim Berners-Lee propose le Web

À la fin des années 1980, **Tim Berners-Lee**, qui travaille au CERN, cherche notamment une manière plus pratique de relier et consulter des informations réparties entre différents systèmes.

En 1989, il propose un projet fondé sur l'hypertexte.

Les éléments fondamentaux associés au Web apparaissent alors progressivement :

- **HTML** pour structurer les documents ;
- **HTTP** pour les échanges ;
- les **URL** pour identifier les ressources ;
- un navigateur ;
- un serveur Web.

Vous retrouvez donc plusieurs mots découverts dans notre cours.

---

# 6. 1990–1991 — Les premiers éléments du Web fonctionnent

En 1990, Tim Berners-Lee développe au CERN les premières briques opérationnelles du Web, notamment un navigateur/éditeur et un serveur Web.

En 1991, le Web commence à être rendu accessible plus largement au-delà de son contexte initial.

À cette époque, les pages sont évidemment beaucoup plus simples que les services Web modernes.

Mais le principe essentiel est déjà là :

```text
une ressource
    ↓
identifiée par une adresse
    ↓
demandée par un client
    ↓
fournie par un serveur
    ↓
reliée à d'autres ressources par des liens hypertextes
```

---

# 7. Les navigateurs rendent le Web plus accessible

Au début des années 1990, différents navigateurs apparaissent et le Web devient progressivement accessible à davantage d'utilisateurs.

Le navigateur **Mosaic**, apparu en 1993, joue notamment un rôle important dans la popularisation du Web graphique.

Dans les années suivantes, la concurrence entre navigateurs devient un élément majeur de l'évolution du Web.

Aujourd'hui, vous utilisez peut-être Chrome, Firefox, Edge ou Safari, mais ces logiciels appartiennent à une histoire déjà longue.

---

# 8. Les moteurs de recherche

À mesure que le nombre de sites augmente, il devient difficile de trouver une information simplement en connaissant l'adresse exacte d'un site.

Des annuaires et moteurs de recherche apparaissent pour indexer et retrouver les contenus du Web.

Cela permet de rappeler une distinction importante :

- **le Web** contient des ressources ;
- **un moteur de recherche** aide à trouver certaines de ces ressources ;
- **un navigateur** permet de les consulter.

Un moteur de recherche n'est donc ni Internet ni un navigateur.

---

# 9. Des pages aux applications Web

Le Web évolue considérablement.

Les premières pages sont surtout des documents à consulter. Progressivement, les sites deviennent interactifs et permettent :

- de créer des comptes ;
- d'envoyer des messages ;
- d'acheter ;
- de publier du contenu ;
- de regarder des vidéos ;
- de collaborer ;
- d'utiliser des applications entières dans un navigateur.

Le navigateur devient ainsi une véritable plateforme applicative.

Nous n'étudierons pas encore cette complexité cette semaine.

---

# 10. Le Web mobile et le cloud

Avec la généralisation des smartphones, tablettes et réseaux mobiles, les services Web doivent être accessibles depuis de nombreux types d'appareils.

Parallèlement, de nombreuses organisations exploitent des infrastructures distantes et des services cloud.

Le Web moderne repose donc sur des systèmes très complexes, même lorsqu'une page semble simple à l'utilisateur.

C'est précisément pour cette raison que nous commençons par les bases.

---

# 11. Et aujourd'hui ?

Le Web actuel combine de nombreuses technologies :

- HTML ;
- CSS ;
- JavaScript ;
- serveurs applicatifs ;
- bases de données ;
- API ;
- systèmes d'authentification ;
- infrastructures réseau ;
- cloud ;
- mécanismes de cybersécurité ;
- applications mobiles et services connectés.

Vous en découvrirez progressivement une grande partie pendant le BTS.

Cette semaine, votre point de départ reste volontairement simple :

```text
Internet
   ↓
Web
   ↓
client / serveur
   ↓
HTTP
   ↓
HTML
```
