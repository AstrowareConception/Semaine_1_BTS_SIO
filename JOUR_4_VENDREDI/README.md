# Mini-projet, tests, présentation et bilan

Aujourd'hui, vous utilisez les connaissances de la semaine dans une petite réalisation collective.

Nous n'ajoutons pas de technologie importante.

## Objectifs

- organiser un petit travail en équipe ;
- transformer une consigne en pages HTML ;
- répartir le travail ;
- produire un mini-site fonctionnel ;
- tester le site d'une autre équipe ;
- corriger des problèmes ;
- présenter le résultat ;
- expliquer sa contribution personnelle.

# Ce qui compte aujourd'hui

Nous ne cherchons pas le « plus beau site ». Sans CSS, les sites resteront visuellement simples.

Nous cherchons surtout :

- une organisation claire ;
- des liens qui fonctionnent ;
- des contenus compréhensibles ;
- des fichiers bien rangés ;
- une équipe capable d'expliquer ce qu'elle a fait.
