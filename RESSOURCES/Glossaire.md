# Glossaire de la semaine

Ce glossaire utilise volontairement des définitions accessibles. Certaines notions seront précisées plus tard pendant le BTS.

## Adresse IP

Adresse utilisée dans les communications utilisant le protocole IP. Pour cette première semaine, retenez qu'elle participe à l'identification et à l'acheminement des communications vers les équipements ou interfaces concernés.

## Balise HTML

Élément de syntaxe permettant de structurer ou décrire le contenu d'un document HTML.

## Client

Dans une architecture client/serveur, logiciel ou système qui demande un service à un serveur. Dans nos exemples Web, le navigateur joue le rôle de client.

## Code HTTP

Nombre présent dans une réponse HTTP permettant notamment d'indiquer le résultat général d'une requête. Exemples découverts : 200, 404, 500.

## DNS

Système de noms utilisé sur les réseaux IP. Il permet notamment de résoudre des noms en informations utiles pour joindre les services, comme des adresses IP.

## Dossier

Conteneur permettant d'organiser des fichiers et éventuellement d'autres dossiers.

## Extension

Partie généralement placée après le dernier point dans un nom de fichier, par exemple `.html` ou `.jpg`.

## Fichier

Ensemble de données enregistré sous un nom, par exemple `index.html` ou `photo.jpg`.

## HTML

HyperText Markup Language. Langage de balisage utilisé pour structurer le contenu de documents Web.

## HTTP

Protocole utilisé pour des échanges sur le Web, suivant notamment un modèle de requêtes et de réponses.

## Internet

Réseau mondial de réseaux interconnectés utilisant des protocoles communs.

## Lien hypertexte

Élément permettant de naviguer vers une autre ressource ou un autre emplacement.

## Navigateur

Logiciel capable notamment de demander, recevoir, interpréter et afficher des ressources Web. Exemples : Firefox, Chrome, Edge, Safari.

## Nom de domaine

Nom lisible par les humains utilisé dans l'adressage de ressources et services sur Internet.

## Réseau informatique

Ensemble d'équipements capables de communiquer entre eux grâce à des moyens et protocoles de communication.

## Requête

Message envoyé pour demander une action ou une ressource à un service.

## Réponse

Message renvoyé en retour d'une requête.

## Serveur

Système ou logiciel qui fournit un service à des clients. Un serveur Web répond à des requêtes Web.

## URL

Adresse permettant d'identifier ou localiser une ressource et le moyen d'y accéder.

## Visual Studio Code

Éditeur de code utilisé pendant cette semaine pour créer et modifier nos fichiers HTML.

## Web

Service utilisant Internet et reposant notamment sur des ressources accessibles grâce à des URL et des échanges HTTP, généralement consultées à l'aide d'un navigateur.
